# 飞牛OS (fnOS) 书库部署说明

用 Docker 在飞牛 NAS 上搭建「阅读服务器 + 小说下载器」，配合本目录整理好的书源使用。

## 一、这个方案解决什么

| 组件 | 作用 | 端口 |
|------|------|------|
| **Kavita** | 书库管理 + 在线阅读（小说 epub/pdf/txt + 漫画 cbz/cbr/zip/rar） | `15000` |
| **go-novel** | 小说批量下载（规则式抓取，Web UI 操作） | `7765` |
| **Komga**（可选） | 漫画专用服务器，备选方案 | `15001` |

数据流：
```
go-novel 下载 ──► /vol1/1000/books/小说 ──► Kavita 自动扫描入库
手动放入 epub/txt ──► /vol1/1000/books/小说 ──► Kavita 自动扫描入库
手动放入 cbz/rar ──► /vol1/1000/books/漫画 ──► Kavita 自动扫描入库
```

## 二、部署步骤（飞牛 OS）

1. **准备目录**（在飞牛文件管理中创建）：
   - `/vol1/1000/books/小说`
   - `/vol1/1000/books/漫画`
   （也可改成你喜欢的路径，但需同步修改 `docker-compose.yml` 中的卷映射）

2. **创建项目**：
   - 打开「Docker」应用 → 点「Compose」→「新增项目」
   - 项目名填 `books`
   - 选择本目录 `fnos-deploy`（含 `docker-compose.yml` 的目录）
   - 点「部署」即可

3. **等待镜像拉取**：
   - 若拉取慢，先在「Docker → 设置 → 镜像加速」配置国内加速器

4. **访问**：
   - Kavita：`http://<NAS-IP>:15000`（首次访问设管理员账号）
   - go-novel：`http://<NAS-IP>:7765`

## 三、使用指南

### Kavita（书库）
- 首次登录后按向导添加「Library」：
  - 小说库 → 选 `/books` 目录，类型选 **Book**
  - 漫画库 → 选 `/manga` 目录，类型选 **Manga/Comic**
- 把文件放进对应目录，Kavita **每分钟自动扫描**，无需手动刷新。

### go-novel（小说下载）
- 网页打开后先填「小说源规则」（可在设置里添加站点规则）。
- 搜索书名 → 选书 → 下载，文件会落到 `/vol1/1000/books/小说`。
- **挖坑提示**：go-novel 是纯下载器，下载后要在 Kavita 里能看到，需确认两点：
  1. 下载目录就是 `/app/downloads`（已映射到小说书库目录）；
  2. Kavita 对该目录已建立 Library。

### 定时同步（自动入库）
- **Kavita** 自带定时扫描（默认每分钟），新文件进来自动入库，无需 cron。
- **go-novel** 的规则抓取是手动触发的；若想定时下载，可在 go-novel Web UI 里配置定时任务，或后续用 cron + curl 调它的 API。

## 四、与书源整理工具的配合

本目录 `..\final_deduped.json` 是整理好的书源（已去重 + 星级分组），可把它拿回到
Legado 手机 App（或 hectorqin/reader 类服务器）导入使用：

- **5★ 源**：搜索命中测试作品 + 目录/正文规则完整 → 优先使用
- **3★ 源**：可达可用，可作补充
- **❌失效分组**：已死的源，不用管

## 五、常见问题

| 问题 | 处理 |
|------|------|
| Kavita 打不开 | 检查端口 `15000` 是否被占用，看容器日志 |
| 拉镜像超时 | 配置镜像加速器后重新部署 |
| 漫画文件夹没入库 | 确认目录里有 cbz/cbr/zip/rar 文件（Kavita 不读散图） |
| go-novel 无法下载 | 目标站点可能反爬，换源或检查规则 |
| 中文小说乱码 | 小说文件需 UTF-8 编码，txt 转 epub 可避免 |

## 六、停止/更新

- 停止：Docker → Compose → books → 停止
- 更新：修改 compose 后点「重新部署」，或删除容器后用同一项目目录重新部署
